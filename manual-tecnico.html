📘 Manual Técnico: Stack Offline-First

Sistema completo de desarrollo freelance para aplicaciones web 100% offline. Funciona con doble clic en index.html, sin servidores, sin CDNs, sin procesos de build. Diseñado para integrarse con OpenCode.ai mediante SKILLs globales.

⚠️ Reglas No Negociables: Prohibido import/export, type="module", fetch y CDNs en runtime. Obligatorio uso de variables globales, rutas relativas y cifrado local con CryptoJS.

📥 Instalación

El sistema utiliza SKILLs globales de OpenCode. No requieren instalación por proyecto.

Terminal (Windows)
mkdir "%USERPROFILE%\.opencode\skills" xcopy /E /I /Y "ruta\clonada\SKILLS-AHAGUILERA\*" "%USERPROFILE%\.opencode\skills\"
Terminal (macOS/Linux)
mkdir -p ~/.opencode/skills cp -r SKILLS-AHAGUILERA/* ~/.opencode/skills/
✅ Tras copiar, reinicia OpenCode: opencode. Las SKILLs se cargarán automáticamente.

🧩 Catálogo de SKILLs

🚀 prompt-inicial

Orquestador maestro. Recibe nombre, tipo, descripción, tono y módulos. Dispara pipeline completo.

Trigger: nuevo proyecto

🛠️ setup-init

Valida entorno, crea estructura de carpetas, genera descargar-libs.bat y verifica integridad.

Trigger: iniciar setup

🎯 spec-creator

Transforma historias en specs técnicas. Flujo interactivo con asunciones, preguntas 4+1 y barra de progreso.

Trigger: definir spec app

🎨 design-ux-intelligence

Aplica principios de diseño, accesibilidad WCAG AA, patrones táctiles y tono visual sin romper offline.

Auto-activada

🛡️ stack-compliance-guard

Valida automáticamente cada output contra @AGENTS.md. Bloquea imports, CDNs y omisión de cifrado.

Auto-activada

💻 code-generator

Genera código por fases (core → módulos). Pausas explícitas para evitar pérdida de contexto en OpenCode.

Trigger: generar codigo

✅ validation-offline

Análisis estático + guía DevTools + checklist UX. Genera reporte en docs/validacion-[app].md.

Trigger: validar app

🔄 Pipeline de Desarrollo

1

Orquestación

Escribe nuevo proyecto. Rellena nombre, tipo, descripción, tono visual y módulos.

2

Setup

iniciar setup → Crea carpetas, config y script de descarga. Ejecuta .bat y confirma.

3

Especificación

definir spec app → Valida asunciones, responde preguntas 4+1, guarda specs/[app].md.

4

Generación

generar codigo → Core primero (pausa), luego módulos uno a uno. Compliance auto-validado.

5

Validación

validar app → Pruebas estáticas, comandos DevTools, reporte técnico y checklist de entrega.

📦

Entrega

ZIP web / instalador Electron + GUIA_USUARIO.pdf + contrato firmado.

🛠️ Solución de Problemas

SíntomaCausa ProbableSolución
Error CORS al abrir index.htmlPresencia de import o type="module"Elimina imports. Usa variables globales y orden correcto de scripts.
Dexie is not definedScript de Dexie no cargó o orden incorrectoVerifica que dexie.js esté antes de core/db.js en index.html.
OpenCode pierde contextoGeneración >15k tokens sin pausaRespeta pausas entre fases. Usa /context clear si se satura.
SKILL no se activaTrigger mal escrito o ruta incorrectaVerifica que esté en ~/.opencode/skills/ y el trigger coincida exactamente.
Datos no persistenNavegador en modo privado o IndexedDB bloqueadaUsa ventana normal. Verifica almacenamiento en DevTools > Application.

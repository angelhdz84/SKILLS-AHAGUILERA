Stack Frontend
Tecnologias que hacen posible apps offline-first rapidas y profesionales
⚒
Alpine.js
Interactividad reactiva en el DOM. Sin build step, sin virtual DOM. Directivas en HTML para estados, eventos y data binding.
Framework UI
🗃
Dexie.js
Wrapper sobre IndexedDB. API simple tipo MongoDB para operaciones CRUD. Queries, indices y bulk operations offline.
Base de datos
🎨
Tailwind CSS
Framework CSS utilitario. Diseno rapido con clases atomicas. Compilado localmente, sin CDN. Responsive por defecto.
Estilos
🌸
DaisyUI 5
Componentes UI accesibles sobre Tailwind. Botones, modales, tabs, formularios. Temas claros y oscuros incluidos.
Componentes
🎥
Bootstrap Icons
Libreria de 2000+ iconos vectoriales. Liviana, consistente y sin dependencias externas. Cargada desde assets locales.
Iconos
🎨
Animate.css
Animaciones CSS declarativas. Fade-ins, slides, zooms para transiciones de pantalla y micro-interacciones.
Animaciones
Stack Datos + IA
Seguridad, inteligencia y exportacion — todo sin conexion a internet
🔒
CryptoJS
Cifrado AES de datos locales. Toda la informacion se encripta antes de guardarse en IndexedDB. Privacidad total del cliente.
Seguridad
📦
pako
Compresion ZIP en el navegador. Reduce el peso de datos exportados y backups. Sin servidor ni librerias del lado servidor.
Compresion
🔍
FlexSearch
Motor de busqueda full-text en el navegador. Resultados en milisegundos sobre miles de registros. Sin API externa.
Busqueda
🧠
Transformers.js
Modelos de IA en el navegador via ONNX. QA extractivo, analisis de sentimiento y clasificacion. 100% offline.
IA
📈
ApexCharts
Graficos interactivos y responsive. Lineas, barras, tortas. Ideales para dashboards de ventas, inventory y KPIs.
Graficos
📄
jsPDF + SheetJS
Generacion de PDF y Excel directamente en el navegador. Facturas, reportes, exportacion de datos. Sin servidor.
Exportacion
🖥
NeutralinoJS
Runtime nativo para el perfil Full. .exe portable (~2MB) con ventana nativa, bandeja de sistema y notificaciones locales.
Runtime .exe
📱
Capacitor
Empaqueta la app como .apk Android nativo con SQLite, cámara, GPS, notificaciones locales y compartir. Sin Google Play Services.
Runtime .apk

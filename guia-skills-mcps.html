📘 Guía de Skills y MCPs

Referencia práctica de las 41 skills instaladas en el sistema, organizadas en 3 categorías, más 8 servidores MCP que las potencian.

💡 Tip: Usa el buscador (Ctrl+F o el campo de búsqueda arriba) para encontrar cualquier skill o comando rápido.

A 🧠 Skills del Stack 7

Pipeline principal para construir apps offline-first. Se activan con triggers explícitos (excepto design-ux y compliance que son auto-activadas).

C 📐 Pattern Libraries 25

Skills pasivas que proporcionan patrones UX, guías de diseño y reviewers especializados. Se activan automáticamente según el contexto. No requieren triggers del usuario.

📋 Formularios y Datos 6

form-patterns UX

Patrones UX para formularios: validación en tiempo real, disposición de campos, manejo de errores inline, wizards multi-paso y confirmación antes de enviar.

list-page-patterns UX

Patrones para páginas de listado/browse: filtros combinados, ordenación por columnas, paginación, vistas grid/table, estados vacío y de carga.

detail-page-patterns UX

Patrones para páginas de detalle: headers con acciones, contenido con tabs, layouts multi-columna, displays de datos relacionados y breadcrumbs.

data-density-patterns UX

Visualización densa de información sin solapamiento: scrolling optimizado, manejo de z-index, responsive condensing y jerarquía visual clara.

info-card-patterns UX

Patrones para tarjetas informativas, displays de entidades y bloques de estadísticas con iconos, etiquetas y datos resumidos.

status-visualization-patterns UX

Visualización de estados de sistema: indicadores en vivo, health bars, badges de estado con color, iconos y animación.

🧭 Navegación y Layout 4

navigation-patterns UX

Sidebar navigation, mobile drawers, breadcrumbs, app shell, pestañas y navegación anidada con estado activo y transiciones.

page-structure-patterns UX

Estructura base de páginas: estados (cargando, vacío, error, éxito), layout estándar, encabezados y contenedores responsivos.

split-panel-patterns UX

Layouts con paneles divididos: divisores redimensionables, multi-panel, sincronización de scroll y persistencia de tamaño.

comparison-patterns UX

Comparaciones lado a lado, diff highlighting (antes/después), y vistas multi-item para contrastar datos visualmente.

🖱️ Interacción 5

interaction-patterns UX

Micro-interacciones: estados de carga, feedback visual, animaciones de transición, hover effects y mecanismos de respuesta del sistema.

drag-drop-patterns UX

Interacciones drag & drop: feedback visual durante arrastre, zonas de drop destacadas, reordenación de listas y validación de destino.

keyboard-shortcuts-patterns UX

Atajos de teclado, paleta de comandos (Cmd+K), teclas de acceso rápido, navegación por teclado y discoverability de shortcuts.

toast-notification-patterns UX

Notificaciones toast, snackbars, alerts y sistema de feedback: posicionamiento, duración, apilamiento, tipos (éxito/error/warning/info).

editor-workspace-patterns UX

Editores multi-pestaña, workspace management, dirty state, validación en tiempo real, undo/redo y UIs de editor complejas.

💬 Modales y Feedback 3

modal-patterns UX

Diálogos modales: confirmación, edición, selector, wizard. Incluye gestión de foco, z-index, backdrop, cierre con Escape y accesibilidad.

playback-replay-patterns UX

Controles de reproducción/replay: timeline, botones play/pause, velocidad, barra de progreso y visualización de eventos temporales.

event-timeline-patterns UX

Líneas de tiempo de eventos: chronological feed, timeline visual, agrupación por fecha, scroll infinito y marcadores de eventos importantes.

📱 Mobile y Accesibilidad 4

mobile-responsive-ux UX

UX móvil: touch targets (44px+), gestos (swipe, pinch), responsive design, bottom sheets, navegación mobile-first y viewport management.

wcag-accessibility a11y

Checklist WCAG 2.2 completo: contraste (AA/AAA), roles ARIA, navegación por teclado, focus visible, etiquetas, screen readers y testing methods.

ux-heuristics UX

10 heurísticas de Nielsen: visibilidad del estado del sistema, consistencia, prevención de errores, reconocimiento, flexibilidad y diseño estético.

turn-based-ui-patterns UX

UIs por turnos: tableros/canvas, indicador de turno actual, historial de movimientos, temporizador y estados de juego activo/pausado.

🎨 Visual y Diseño 3

visual-design-system UI

Principios de diseño visual: layout grid, jerarquía tipográfica, teoría del color, sistemas de espaciado (8px), elevación y sombras.

canvas-grid-patterns UX

Patrones para interfaces de canvas/grid: cuadrículas interactivas, zoom, pan, selección múltiple, alineación y snapping.

react-ux-patterns legacy

Patrones UX específicos para React/Next.js: state management, data fetching, server components y componentes reutilizables. Legacy — el stack usa Alpine.js.

🎬 Escenarios de Uso

🚀 Escenario 1: Crear app desde cero

Pipeline completo desde la idea hasta la app validada.

  1. Prompt inicial: escribe nuevo proyecto. Llena 5 campos: nombre, tipo, descripción, tono visual, módulos.
  2. Setup: iniciar setup. Crea carpetas, project.config.js, descarga librerías. Dale ✅ FASE 1 OK.
  3. Spec: definir spec app. Responde asunciones + preguntas 4+1. Se genera specs/[app].md. Dale ✅ FASE 2 OK.
  4. Diseño: design-ux se activa si diste tono visual. Propone paleta, tipografía, componentes.
  5. Generación: generar codigo. Fase A: core + index.html. Pausa. Fase B: módulos uno a uno.
  6. Validación: validar app. Estático + DevTools + a11y + Playwright. Genera docs/validacion-[app].md.

🛡️ Escenario 2: Corregir compliance en app existente

Tienes código de otro proyecto y quieres asegurar que cumple el stack offline-first.

  1. Abre OpenCode en la carpeta del proyecto.
  2. Escribe validar stack. Escanea todos los archivos buscando violaciones (imports, CDNs, cifrado).
  3. Corrige automático lo reparable; pregunta si es ambiguo.
  4. Recibe resumen: bloqueados, corregidos, pendientes.
Tú: validar stack
→ 3 violaciones: 1 import, 2 CDNs
→ Corrigiendo... 2 CDNs → rutas relativas
→ Pregunta: el import es parte de lib permitida? Tú: No, elimínalo.
→ ✅ Stack compliant.

🎨 Escenario 3: Mejorar diseño y accesibilidad

Tu app funciona pero quieres darle un look profesional + WCAG AA.

  1. Escribe mejorar UI o tono visual moderno. design-ux se activa.
  2. Propone paletas, tipografías y espaciado basados en marcas reales (vía refero-styles MCP).
  3. Selecciona una propuesta. design-ux actualiza variables CSS en project.config.js.
  4. Escribe validar accesibilidad. El MCP a11y audita contraste, ARIA, foco y etiquetas.
  5. Corrige los issues reportados.

📄 Escenario 4: Usar agent skills para documentos

Necesitas exportar resultados a formatos de oficina.

  1. Word: crea un documento Word con el reporte de validación → skill docx genera .docx.
  2. Excel: exporta estos datos a Excel → skill xlsx genera .xlsx con fórmulas.
  3. Presentación: haz una presentación de la propuesta → skill pptx genera .pptx.
  4. PDF: convierte el informe a PDF → skill pdf genera .pdf.

Exportar Configuración

Descarga el archivo brand.config.json con toda la configuración de marca.

¿Importar configuración? Se sobrescribirá la marca actual.
¿Estás seguro? Se perderán todos los cambios.

¿Cómo usar este archivo?

  1. Coloca brand.config.json en la misma carpeta del .exe o index.html
  2. La app lo detectará automáticamente al iniciar
  3. Los cambios se aplican en vivo, sin recompilar
  4. Para distribuir a un cliente, copia el ZIP completo con el archivo incluido
  5. En Neutralino: usa "Guardar en disco" para sobrescribir el archivo junto al .exe
  6. Para importar en otra app: abre Personalizar Marca → Exportar → Importar → selecciona el archivo
